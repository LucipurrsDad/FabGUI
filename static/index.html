How to use FabGUI

  • Use the centered tabs in the header to sort by newest engine or alphabetically.
  • Search and filter the owned library by engine, category, distribution format, or target platform.
  • Click a card to open the download prompt; right-click to copy its listing UID.
  • Latest engine sorts by each item's highest listed Unreal Engine version; it does not identify a complete Unreal project.
  • Authentication is handled through FabCLI.
