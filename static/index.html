How to use FabGUI

  • Click a card to open the download prompt; right-click to copy its listing UID.
  • Use the pinned sort tabs and filters to browse the owned library by engine, category, format, or platform.
  • Categories and filter counts come from the items in your Fab library response.
  • Latest engine sorts by each item's highest listed Unreal Engine version; it does not claim that every listing is a project.
  • Downloads are stored in the configured FabCLI output folder.
  • Authentication is handled through FabCLI.
