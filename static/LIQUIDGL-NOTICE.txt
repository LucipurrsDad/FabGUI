# liquidGL integration notice

FabGUI loads the `liquid-gl` JavaScript module (version 3.0.0) from jsDelivr at runtime. The liquidGL source code is not vendored in this repository. liquidGL is © NaughtyDuk and is licensed under the MIT License; see <https://github.com/naughtyduk/liquidGL/blob/main/package/LICENSE> for the license terms.

FabGUI does not copy or redistribute liquidGL's demo media. The wallpaper is selected by the user from their own device and stored locally in the browser's IndexedDB when browser storage permits.
