# liquidGL integration notice

FabGUI vendors the `liquidGL` v3.0.0 browser script in `static/liquidGL/`.
liquidGL is © NaughtyDuk and is licensed under the MIT License; see
`static/liquidGL/LICENSE` for the license terms.

FabGUI uses liquidGL to render the header and asset cards as refracting glass
panes. The remaining glass surfaces use the same tint and frost variables as a
CSS fallback. FabGUI does not copy or redistribute liquidGL's demo media.
